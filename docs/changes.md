- An overview with a bare tag or brace outside code (`GetComponent<Renderer>()`) fails to render as MDX (UNI-1046); Pebble's writer or the renderer needs a fallback
- The Spans page has no Back or title, though Issue Traces rows open it directly
- Switching branch in platform's Repos browser goes back to the repository root instead of keeping the open path (moot since #215 removed the browser)

- A queued job run has no live sandboxes, so Sandboxes can't name its Agent ("Job run <id>"); a reservation carrying its creator would fix it
